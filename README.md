# How to install
find *product* repository, chose version and open it, two files are available, download both of them and place in same folder. Than run .exe file in repository on your computer.

# Game controls
- *interact* 'R'
- *attack* 'left mouse click'
- *move* 'wasd'
- *switch meele/magic* 'E'
- *block* 'right mouse click' (developed)
